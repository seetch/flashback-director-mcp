# Local Flashback JARs

Place the proprietary Flashback mod JAR files here for local compilation (`compileOnly`).
These files are ignored by Git (`libs/*.jar` in `.gitignore`) and must never be committed.

Expected filenames (configurable in `gradle.properties`):
- `Flashback-0.43.6-for-MC26.2.jar` (for `mc-26.2`)
- `Flashback-for-MC26.3.jar` (for `mc-26.3`)
